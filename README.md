# 📊 Sales Dashboard

An interactive **Sales Performance Dashboard** built using Microsoft Excel.

### Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers

### Project Workflow
Kaggle Dataset → Data Cleaning → Pivot Analysis → Dashboard

### Dashboard
The dashboard provides insights into:
- Total Sales & Profit
- Orders & Quantity
- Monthly Sales Trend
- Sales by Category & Segment
- Sales by State
- Top 5 Cities by Sales

### Files
- `Sales_Dashboard.xlsx` — Excel workbook containing the dataset, pivot analysis and dashboard.
- `dashboard.png` — Dashboard preview.
